# PowerShell-Skripte

## Ziel

Sammlung für eigene PowerShell-Skripte und kurze Hinweise zur Nutzung.

## Hinweise

- Skripte nur mit klarer Beschreibung ablegen.
- Parameter und Voraussetzungen kurz dokumentieren.
- Keine Passwörter, Tokens oder Kundendaten speichern.
- Vor produktiver Nutzung in einer Testumgebung prüfen.
