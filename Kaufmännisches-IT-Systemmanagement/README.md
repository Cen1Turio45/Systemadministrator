## Worauf man achten muss

- Technische Empfehlung muss zur wirtschaftlichen Anforderung passen.
- Zubehör, Lizenz, laufende Kosten und Lieferbarkeit immer mitdenken.
- Angebote müssen nachvollziehbar begründet werden können.

## Sinnvolle nächste Themen

- Rechnungsprüfung für IT-Leistungen.
- Angebot für Hardware/Software vorbereiten.
- Ablauf von Anfrage, Angebot, Umsetzung und Abrechnung.
